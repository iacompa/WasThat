# WasThat 0.1.0 — M0 developer preview

**Pre-alpha. Version 0.1.0, build 1.** This release shares the initial app skeleton and process-audio recorder. The release targets developer evaluation. The planned notification and sound-identification workflow is not complete.

[Download WasThat.dmg](https://github.com/iacompa/WasThat/releases/download/v0.1.0/WasThat.dmg) · [Versioned DMG](https://github.com/iacompa/WasThat/releases/download/v0.1.0/WasThat-0.1.0.dmg) · [GitHub source](https://github.com/iacompa/WasThat/tree/v0.1.0) · [GPLv3](https://github.com/iacompa/WasThat/blob/v0.1.0/LICENSE)

## Included

- A native SwiftUI menu bar panel with an **Open full log** history window.
- An embedded headless agent that observes process audio activity through CoreAudio property listeners.
- Raw `audio_start` and `audio_stop` events with process names, bundle IDs, timestamps, and durations.
- A shared local SQLite store. The UI shows events from the last hour, with a maximum of 500 rows.
- Universal binaries for Apple silicon and Intel, targeting macOS 14.2 or later.
- Developer ID signatures from IA COMPA LLC, Apple notarization, and stapled tickets for both app and DMG.
- No third-party runtime dependencies, analytics, account, or automatic update service.

The app stores event metadata locally. It does not save audio samples. The agent removes rows older than seven days when it starts.

## Install and recorder behavior

1. Download the DMG.
2. Open the DMG.
3. Drag WasThat into Applications.
4. Open WasThat from Applications.
5. Select the question-mark bubble in the menu bar.

**M0 does not automatically enable the recorder.** This release has no recorder toggle and does not register its embedded login item. Opening the app alone does not collect events. A fresh installation normally shows an empty list.

The panel's **“Scan-only mode”** text indicates an unregistered login item. This release does not perform a retrospective scan.

Developers can start the embedded agent from Terminal:

```bash
"/Applications/WasThat.app/Contents/Library/LoginItems/WasThatAgent.app/Contents/MacOS/WasThatAgent"
```

Keep the Terminal session open while you evaluate the recorder. Press **Control-C** in that Terminal to stop it. This command does not register a login item. Quitting WasThat does not stop the separately started agent.

## Known limits

- Notification parsing, suppression explanations, and event correlation are future work.
- Mute actions, settings links, replay, rarity ranking, a global hotkey, onboarding, and recorder controls are future work.
- Browser activity appears at the process level. The app does not identify individual tabs.
- The agent checks event retention at startup. Continuous retention maintenance is not implemented.
- The separate mute probes recorded peak 0 and detected no nonzero audio in two runs. Owner listening checks were inconclusive. Per-app muting remains unproved.
- The final notification probe observed a suppressed playback decision. It did not establish audible notification playback.
- Runtime checks used Apple silicon and macOS 27.0.1. Intel hardware and older supported macOS versions were not tested.
- One recorder duration was shorter than expected and did not recur in a follow-up. Its cause remains unresolved.

## Verification

Debug and Release builds passed without Swift compiler warnings. Both app bundles contain `arm64` and `x86_64` slices. Strict signature checks passed. Apple accepted app and DMG submissions, and both staples passed checks.

A quarantined DMG passed Gatekeeper assessment. The mounted app passed assessment and started. Recorder smoke checks produced start/stop pairs for test sounds. A 60-second idle check showed no measured CPU-time increase.

The notification spike privacy regression suite passed 42 checks. Independent source and release-evidence reviews passed after the documented repairs. These results establish the tested preview behavior and packaging. They do not establish future milestone functionality.

See the [M0 verification report](https://github.com/iacompa/WasThat/blob/v0.1.0/docs/test-reports/2026-11-m0-codex.md) for commands, results, and limitations.
