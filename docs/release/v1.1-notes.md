# WasThat

Version 1.1 · macOS 14.2+ · Developer ID signed

- Start and stop detection from the app.
- See app names and icons in recent activity and history.
- See notification attempts that macOS reports as silenced.
- See apps currently using audio, with clearer detection and error status.
- Open available source apps and relevant settings, including Login Items for recognized background alerts.

Notification history may be incomplete, and unidentified senders stay unconfirmed. Notification settings opens the general page, where you choose the named app if listed. Links cannot reopen a specific notification, message, or browser tab. Sounds within ongoing app audio may not create new entries, and activity does not prove that a sound was audible.
